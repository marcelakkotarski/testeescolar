## Coleta segura
O frontend permanece bloqueado até existir um endpoint Apps Script da recuperação. **Não use o endpoint da prova anterior**, pois as chaves de resposta são diferentes. O backend deve guardar o gabarito e gravar exclusivamente na aba privada **Resultado 2** da planilha atual. Após implantar o backend, inserir a URL /exec em config.js. Não publicar o gabarito em GitHub.

## Publicação em repositório exclusivo
A integração GitHub disponível nesta conversa não permite criar repositórios. Por isso o site está em `recuperacao/` no repositório existente até a criação manual do repositório `recuperacao`. Para a migração, copiar os arquivos desta pasta para a raiz do novo repositório e ativar Pages.
